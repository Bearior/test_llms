# Thai Banking Document Types — Catalogue

**94 canonical physical types** (de-duplicated from **116 business labels** in `thai_documents_list.xlsx`), grouped into **7 visual families**.

> Numbering is global (1–94), matching the ids the classifier emits. **id 0 = `__UNKNOWN__`** is the abstention / human-review route. Families are scan-aid groupings only — they do not constrain the model's choice (evidence-first, single pass).
